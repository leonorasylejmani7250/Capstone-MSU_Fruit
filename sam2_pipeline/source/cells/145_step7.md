## Step 7 · Use it on new video: count the clusters
The automatic pipeline (a detector finds the clusters, SAM 2.1 segments and follows them) runs over a video in chunks that share one frame. Each chunk is handed the clusters the one before it was following, so a cluster keeps one id for as long as it is in view. Output: an overlay video, a per-frame count, one row per cluster, and the total.

The total is *the clusters the pipeline followed*, not a hand count and not yield. A cluster that is hidden and comes back gets a new id, a missed cluster is not counted, and a leaf taken for a cluster is. Check it against a hand count of one row before using it, and turning cluster counts into kilograms needs a calibration against hand-harvested vines.
